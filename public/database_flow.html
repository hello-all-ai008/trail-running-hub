Database Flow & Schema (TrailTime)

1. Entity Relationship Diagram (ERD)

erDiagram RUNNERS { string bib PK string name string gender string age_group string nationality string category_id FK timestamp created_at } CATEGORIES { string id PK "e.g., MKT10" string name float distance_km string unit "e.g., km" } LOCATIONS { string id PK "e.g., LOC_01" string name float latitude float longitude string url } STATIONS { string id PK "e.g., START, A1" string name string type "START|CP|FINISH" int sequence_order } SCAN_LOGS { uuid id PK string runner_bib FK string station_id FK string location_id FK timestamp scan_time boolean is_valid string note } RUNNERS ||--o{ SCAN_LOGS : "has" CATEGORIES ||--|{ RUNNERS : "contains" STATIONS ||--o{ SCAN_LOGS : "records" LOCATIONS ||--o{ SCAN_LOGS : "happens_at"

2. Table Structures

2.1 RUNNERS (ข้อมูลนักวิ่ง)

Field NameData TypeDescription
bibVARCHAR (PK)หมายเลขบิบ (เช่น "1001")
nameVARCHARชื่อ-นามสกุล
genderVARCHARเพศ (M/F)
age_groupVARCHARรุ่นอายุ
category_idVARCHAR (FK)รหัสระยะทาง (อ้างอิง CATEGORIES)

2.2 CATEGORIES (ระยะการแข่งขัน)

Field NameData TypeDescription
idVARCHAR (PK)ตัวย่อระยะ (เช่น "MKT10", "PST50")
nameVARCHARชื่อเต็มของระยะ
distance_kmFLOATระยะทาง
unitVARCHARหน่วยวัดระยะทาง (เช่น "km")

2.3 LOCATIONS (สถานที่จริง)

Field NameData TypeDescription
idVARCHAR (PK)รหัสสถานที่ (เช่น LOC_01)
nameVARCHARชื่อสถานที่
latitudeFLOATละติจูด
longitudeFLOATลองจิจูด
urlVARCHARลิงก์แผนที่ (เช่น Google Maps)

2.4 STATIONS (จุดสแกน)

Field NameData TypeDescription
idVARCHAR (PK)รหัสจุด (START, A1, FINISH)
nameVARCHARชื่อจุดสแกน
typeENUMประเภท (START, CHECKPOINT, FINISH)
sequence_orderINTลำดับของจุด

2.5 SCAN_LOGS (ประวัติการสแกน Check Point)

Field NameData TypeDescription
idUUID (PK)รหัสรายการ
runner_bibVARCHAR (FK)บิบนักวิ่ง
station_idVARCHAR (FK)จุดที่สแกน (ลำดับในการแข่ง)
location_idVARCHAR (FK)สถานที่จริงที่สแกน
scan_timeTIMESTAMPเวลาที่สแกน
is_validBOOLEANเช็คว่าถูกต้อง (ไม่ได้สแกนซ้ำ)
noteVARCHARหมายเหตุการสแกนผิดพลาด

3. Data Flow

  1. Pre-race: นำเข้าข้อมูลลงตาราง RUNNERS และกำหนดสถานที่ LOCATIONS
  2. Start: สแกนบิบที่จุดปล่อยตัว -> บันทึกลง SCAN_LOGS พร้อมระบุ location_id
  3. Check Point: สแกนระหว่างทาง -> บันทึกลง SCAN_LOGS (ระบบเช็คว่าผ่าน Start มาหรือยัง)
  4. Finish: สแกนเข้าเส้นชัย -> บันทึกเวลาลง SCAN_LOGS -> คำนวณเวลาเพื่อแสดงผล
